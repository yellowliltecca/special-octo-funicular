# AMG Tattoo — концепт сайта

Адаптивный сайт-визитка для тату-салона AMG в Энгельсе. Стек: HTML, CSS, JavaScript без фреймворков.

## Структура
- `index.html` — секции сайта, навигация, контакты и ссылки на карточку организации.
- `styles.css` — тёмная визуальная система и адаптивная верстка.
- `script.js` — мобильное меню, фильтр визуальной галереи, появление элементов при прокрутке.
- `assets/` — четыре сгенерированных изображения в WebP.

## Изображения
Все изображения в `assets/` созданы специально для демонстрационного макета. Они не являются реальными фотографиями AMG или портфолио его мастеров. Перед публикацией их желательно заменить настоящими работами и фотографиями студии.

## Проверенные сведения
- В Яндекс Картах AMG указана как тату-салон по адресу: Комсомольская улица, 162, Энгельс.
- В карточке услуг упоминаются татуировки, пирсинг, эскизы и подарочные сертификаты.
- Телефон, цены, мастера и расписание в проект не добавлялись, поскольку надёжно подтвердить их не удалось.
